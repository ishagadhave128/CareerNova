# CareerNova – Career Intelligence Platform

## About the Project
CareerNova is a web-based career guidance platform designed to help students and job seekers explore career opportunities, identify skill gaps, and prepare for their desired careers.

## Features
- **Career Recommendation:** Recommends suitable career paths based on user skills and interests.
- **Skill Gap Analysis:** Identifies missing skills for selected career paths.
- **Learning Roadmaps:** Provides step-by-step learning paths for different careers.
- **Job Description Matcher:** Compares user skills with job requirements.
- **Resume Analyzer:** Analyzes PDF resumes and identifies relevant skills.
- **Career Smart Assistant:** Provides predefined guidance about careers, programming and interview preparation.

## Installation and Setup

1. Clone this repository.
2. Open the project folder.
3. Install the required packages:

```bash
pip install -r requirements.txt
```

4. Run the Flask application:

```bash
python app.py
```

5. Open your browser and visit:

`http://127.0.0.1:5000/`

## Project Purpose
The purpose of CareerNova is to help users understand career requirements, improve their skills and prepare for job opportunities through a single platform.
